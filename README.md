# Programação Orientada a Objetos (Java) — IFCE

Repositório destinado aos projetos e atividades de Programação Orientada a Objetos (POO) desenvolvidos em Java durante o Curso Técnico em Informática do IFCE — Campus Maranguape.

As atividades e projetos deste repositório foram propostos pelo professor Roger, como parte dos estudos de desenvolvimento de software em Java.

---

## 📚 Conteúdo

Aqui serão armazenados os projetos e exercícios desenvolvidos durante a disciplina, aplicando os conceitos fundamentais de POO, tais como:

* Projetos em Java praticando a Orientação a Objetos
* Implementação de conceitos de modelagem e desenvolvimento de software
* Resolução de problemas e desafios propostos em aula
